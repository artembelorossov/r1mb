# Telegram Auction Bot (MVP)

Минимально рабочий бот для аукциона между друзьями:

- канал с лотами;
- личный чат с ботом (`/start`, `/my_lots`);
- ставки через inline-кнопки;
- авто-добавление лота в избранное при ставке;
- отслеживание реакции ❤️ для списка «Мои лоты»;
- пометка лидирующих лотов как `❤️‍🔥`;
- подготовленный слой для выгрузки статистики (заглушка под Google Sheets).

## Что уже умеет

### Публикация лота админом

Админ отправляет боту **фото с подписью-командой**:

```text
/new_lot <номер>|<название>|<описание>|<начальная_цена>|[шаг_ставки]
```

Пример:

```text
/new_lot 7|Фломастеры|Набор из 24 цветов|150|50
```

Бот публикует пост в канале с:

- фото;
- номером лота;
- названием;
- описанием;
- начальной ценой;
- текущей ставкой `(@ник)`;
- кнопкой `повысить ставку - 50р` или `повысить ставку - 0р` (первая ставка);
- кнопкой `отменить ставку` (видна, когда есть активная ставка);
- кнопкой `мои лоты` (deeplink в личный чат бота).

### Ставки

- Кнопка `повысить ставку`:
  - первая ставка = начальная цена;
  - последующие = + шаг ставки.
- После ставки:
  - лот обновляется в канале;
  - пользователю автоматически ставится реакция ❤️;
  - лот добавляется в «Мои лоты».

### Отмена ставки

- Кнопка `отменить ставку` доступна в посте.
- Отменить может только пользователь, у которого сейчас лидирующая ставка.
- После отмены возвращается предыдущая лидирующая ставка (если была), иначе текущая ставка очищается.

### Мои лоты

В личном чате:

- `/start` показывает кнопку «Посмотреть»;
- `/my_lots` или кнопка «Посмотреть» выводит лоты с ❤️;
- лоты, где пользователь лидирует, помечаются как `❤️‍🔥`;
- в блоке лидирующих лотов считается сумма;
- все строки — ссылки на сообщения в канале.

Пример вывода:

```text
❤️‍🔥 лот #1 карандаши - 100р
❤️‍🔥 лот #7 фломастеры - 150р
Сумма - 250р
❤️ лот #5 ручки - 200р (@nick)
```

## Технический стек

- Python 3.12+
- aiogram 3
- SQLite (aiosqlite)

## Быстрый старт

1. Установить зависимости:

```bash
pip3 install --break-system-packages -r requirements.txt
```

2. Создать `.env` на основе примера:

```bash
cp .env.example .env
```

3. Заполнить `.env`:

```env
BOT_TOKEN=<token>
AUCTION_CHANNEL_ID=-1001234567890
ADMIN_USER_IDS=11111111,22222222
DEFAULT_BID_STEP=50
DATABASE_PATH=auction.db
```

4. Запустить:

```bash
python3 -m auction_bot.main
```

## Важные настройки Telegram

Чтобы работали реакции и callback-кнопки:

- добавьте бота админом в канал;
- дайте право публиковать/редактировать сообщения;
- в BotFather отключите privacy mode (если требуется для вашего сценария);
- убедитесь, что в канале разрешены реакции.

## Google Sheets и альтернативы

Сейчас в проекте есть заглушка `auction_bot/services/google_sheets.py`.
Туда можно подключить:

1. **Google Sheets** (просто и наглядно, удобно для маленьких аукционов);
2. **Supabase** (удобнее для аналитики, фильтров и API);
3. **Airtable** (табличный UI + API, компромисс между Sheets и БД).

Для вашего кейса «между друзьями» стартовать проще всего с Google Sheets или сразу с Supabase, если хотите отчеты/дашборды.
