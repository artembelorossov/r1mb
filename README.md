# Telegram-аукцион для друзей

MVP-бот для аукциона в **forum-группе Telegram (Premium)** с 5 топиками:

1. Админка (создание лотов)
2. Инфо
3. Аукцион
4. Статистика (заготовка)
5. Мои лоты

## Что уже реализовано

- Добавление лота через админ-топик (`/add_lot`, пошаговый сценарий)
- Публикация лота в топик аукциона:
  - фото
  - номер, название, описание
  - начальная цена
  - текущая ставка и лидер
- Кнопки под лотом:
  - `Повысить ставку +0р` (если ставок еще нет)
  - `Повысить ставку +50р` (или другой шаг из `BID_STEP`)
  - `Отменить мою ставку` (работает только для лидера)
- Авто-добавление лота в «избранное», если пользователь делает ставку
- Учет лайков-реакций ❤️ для избранного (через `message_reaction` update)
- Топик «Мои лоты»:
  - кнопка «Посмотреть»
  - список всех отслеживаемых лотов
  - пометка `❤️‍🔥` для лидирующих
  - суммарная текущая стоимость лидирующих лотов
- Хранение данных в SQLite

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m bot.main
```

## Настройки (`.env`)

- `BOT_TOKEN` — токен бота
- `AUCTION_CHAT_ID` — ID вашей forum-группы
- `ADMIN_TOPIC_ID` — topic id для админки
- `INFO_TOPIC_ID` — topic id для инфо
- `AUCTION_TOPIC_ID` — topic id для лотов
- `STATS_TOPIC_ID` — topic id для статистики (сейчас резерв)
- `MY_LOTS_TOPIC_ID` — topic id для «моих лотов»
- `ADMIN_USER_IDS` — id админов через запятую
- `BID_STEP` — шаг увеличения ставки (по умолчанию 50)
- `DATABASE_PATH` — путь к SQLite базе

## Команды

- `/help`
- `/add_lot` — только админ, только в админ-топике
- `/cancel` — отменить пошаговое добавление лота
- `/publish_my_lots_panel` — опубликовать кнопку «Посмотреть» в топике «Мои лоты»
- `/publish_info <текст>` — опубликовать инфо-пост
- `/my_lots` — принудительно вывести список «моих лотов»

## Примечания

- Бот хранит данные локально в SQLite.  
- Для дальнейшей аналитики можно добавить экспорт в Google Sheets, Airtable или Notion API.
